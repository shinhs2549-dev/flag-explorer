# 국기 탐험대

국기를 보고 나라 이름, 지도 위치, 수도를 맞히는 아이용 지리 놀이 앱입니다.
인터넷 주소 하나로 열리고, 홈 화면에 추가하면 앱처럼 전체 화면으로 쓸 수 있습니다.

---

## 1. 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 본체 (지도, 국기, 캐릭터, 스티커 그림이 모두 들어 있음) |
| `manifest.webmanifest` | 홈 화면에 표시될 앱 이름과 아이콘 설정 |
| `sw.js` | 한 번 열고 나면 인터넷이 없어도 열리게 하는 설정 |
| `icons/` | 분홍 아이콘 (기본) |
| `icons/blue/` | 파란 아이콘 (바꾸고 싶으면 `icons/` 안의 같은 이름 파일과 바꿔 넣기) |

---

## 2. GitHub에 처음 올리기

1. GitHub에 로그인하고 오른쪽 위 **+ → New repository**를 누릅니다.
2. 이름을 정하고(예: `flag-explorer`) **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. **uploading an existing file**(또는 **Add file → Upload files**)을 누릅니다.
4. 위 파일들과 `icons` 폴더를 통째로 끌어다 놓고 아래 **Commit changes**를 누릅니다.
5. **Settings → Pages**로 가서 Branch를 `main`, 폴더를 `/(root)`로 고르고 **Save**를 누릅니다.
6. 1~2분 뒤 같은 화면 위쪽에 주소가 나타납니다.
   `https://내아이디.github.io/flag-explorer/`

---

## 3. 홈 화면에 추가하기

### 아이폰 · 아이패드 (사파리)
1. **사파리**로 위 주소를 엽니다. 다른 브라우저 말고 꼭 사파리에서 하세요.
2. 화면 아래(아이패드는 위)의 **공유 버튼**(네모에서 화살표가 위로 나온 모양)을 누릅니다.
   공유 버튼이 안 보이면 주소창 옆 **⋯** 버튼을 누른 뒤 **공유**를 누릅니다.
3. 목록을 아래로 내려 **홈 화면에 추가**를 누릅니다.
4. 이름이 '국기 탐험대'로 되어 있는지 확인하고, **웹 앱으로 열기**가 보이면 켜 둔 채로 오른쪽 위 **추가**를 누릅니다.
5. 홈 화면에 생긴 아이콘으로 엽니다. 주소창 없이 앱처럼 열리면 성공입니다.

> 아이폰에서는 **사파리에서 연 기록과 홈 화면 앱의 기록이 따로 저장**됩니다.
> 처음부터 홈 화면 아이콘으로만 열어 주세요.

### 안드로이드 · 갤럭시 탭 (크롬)
1. **크롬**으로 위 주소를 엽니다.
2. 오른쪽 위 **⋮** 를 누르고 **앱 설치** 또는 **홈 화면에 추가**를 누릅니다.
3. **설치**를 누르면 홈 화면과 앱 목록에 아이콘이 생깁니다.

## 4. 소리가 안 나올 때

- **아이폰 무음 모드**: 옆면 무음 스위치(또는 제어 센터의 무음)가 켜져 있으면 효과음과 읽어 주는 소리가 작거나 안 날 수 있습니다. 무음을 끄고 볼륨을 올려 주세요.
- **한국어 음성이 어색하거나 안 나올 때**
  - 아이폰·아이패드: **설정 → 손쉬운 사용 → 콘텐츠 말하기 → 음성 → 한국어**에서 '유나' 같은 음성을 받으면 발음이 좋아집니다.
  - 안드로이드: **설정 → 일반(또는 접근성) → 텍스트 음성 변환**에서 한국어 음성 데이터를 설치합니다.
- 앱을 열고 **화면을 한 번 누른 뒤부터** 소리가 납니다. 브라우저 규칙이라 정상입니다.

## 5. 기록(별, 스티커, 보물 카드) 지키기

- 기록은 **그 기기 안에만** 저장됩니다. 앱을 끄거나 기기를 껐다 켜도 유지됩니다.
- 다음 경우에는 지워질 수 있습니다.
  - 브라우저 설정에서 방문 기록이나 사이트 데이터를 지울 때
  - 홈 화면 앱(아이콘)을 삭제할 때
- 그래서 가끔 **백업 코드**를 받아 두세요.
  1. 처음 화면 오른쪽 위 **톱니바퀴를 1초 정도 길게** 누르면 보호자 메뉴가 열립니다.
  2. **백업 코드 복사**를 누르고, 카카오톡 '나와의 채팅' 등에 붙여 넣어 보관합니다.
  3. 기록이 지워졌거나 기기를 바꿨다면, 같은 메뉴의 칸에 코드를 붙여 넣고 **되살리기**를 두 번 누릅니다.

## 6. 보호자 메뉴 (톱니바퀴 길게 누르기)

| 항목 | 설명 |
|---|---|
| 통과 기준 | 통과 테스트 15문제 중 몇 개를 맞혀야 통과인지 (기본 11개) |
| 오늘 테스트 다시 열기 | 테스트에 떨어져서 '내일 다시'가 된 것을 바로 풀어 줌 |
| 한 번에 공부할 나라 수 | 한 판에 나오는 나라 수 (5, 10, 15개) |
| 모든 별 단계·테스트 열기 | 보호자가 미리 살펴볼 때 사용 |
| 말하기 속도 | 보통 / 천천히 |
| 기록 백업 · 되살리기 | 위 5번 참고 |
| 기록 모두 지우기 | 두 번 눌러야 지워짐. 되돌릴 수 없으니 먼저 백업하세요 |

## 7. 앱을 고친 뒤 다시 올릴 때

1. 바뀐 파일만 저장소에 **Add file → Upload files**로 올리면 같은 이름 파일이 덮어써집니다.
2. `index.html`을 바꿨다면 **`sw.js`도 같이 올려 주세요.** `sw.js` 첫 줄의 버전 숫자(`flag-explorer-v3`)가 올라가야 태블릿이 새 버전을 받습니다.
3. 기기에서 앱을 **완전히 닫았다가 다시 열면** 새 버전이 적용됩니다. 한 번에 안 바뀌면 한 번 더 껐다 켜 주세요.
4. 기록은 그대로 남습니다.
