# 국기 탐험대

국기, 나라 위치, 수도를 배우는 아이용 웹앱입니다. GitHub Pages에 올리면 태블릿 홈 화면에 앱처럼 추가할 수 있습니다.

## 파일
- `index.html` — 앱 전체 (지도, 국기, 캐릭터 그림 포함)
- `manifest.webmanifest` — 홈 화면 앱 이름, 아이콘 설정
- `sw.js` — 인터넷이 없어도 열리게 하는 저장 설정
- `icons/` — 분홍 아이콘 (기본)
- `icons/blue/` — 파란 아이콘 (바꾸고 싶을 때 `icons/` 안의 같은 이름 파일과 바꿔 넣기)

## 앱을 고친 뒤 올릴 때
`index.html`을 바꿔 올린 다음 `sw.js` 첫 줄의 `flag-explorer-v1`을 `v2`, `v3`처럼 올려 주세요. 그래야 태블릿이 새 버전을 확실히 받습니다.

## 기록
기록은 태블릿 안에만 저장됩니다. 보호자 메뉴(톱니바퀴 길게 누르기)에서 백업 코드를 복사해 두면, 기록이 지워져도 되살릴 수 있습니다.
